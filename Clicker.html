🚀 Инструкция по установке

1

Создайте бота в Telegram

Откройте @BotFather, создайте бота и скопируйте токен

2

Скачайте файлы

Скачайте bot.py и создайте .env файл

mkdir cryptominer-bot && cd cryptominer-bot # Скачайте bot.py в эту папку
3

Настройте .env

Создайте файл .env рядом с bot.py

BOT_TOKEN=ваш_токен_бота
ADMIN_IDS=ваш_telegram_id
FLYER_KEY=
HIVIEWS_API_KEY=
4

Запустите бота

Зависимости установятся автоматически

python bot.py
5

Используйте админ-панель

Отправьте /admin в боте для настройки
